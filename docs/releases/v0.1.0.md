# v0.1.0 — First public reliability core

`v0.1.0` establishes the first deliberately small public API for Market Data Reliability Core. The release focuses on deterministic, provider-independent safeguards that can sit before research, backtesting, dashboards, or trading systems without embedding any vendor SDK or trading decision logic.

## Highlights

- Immutable source observations with deterministic fingerprints.
- Replay-safe in-memory ingestion that distinguishes duplicates from identity collisions.
- Explicit provider-field normalization into canonical OHLCV bars.
- Canonical decimal policy that rejects binary floats and non-finite values.
- Validation for OHLC consistency, volume, duplicates, missing intervals, interval validity, and bar duration.
- Point-in-time universe membership semantics to help prevent survivorship bias.
- Deterministic multi-source lineage for derived records.
- Historical-correction preconditions using compare-before-apply semantics.
- Frozen package-root API documented in `docs/PUBLIC_API.md`.

## Verification

The release candidate is verified on Python 3.11, 3.12, and 3.13 with lint, strict type checking, tests, and package builds. CI also builds a wheel, installs it into a clean environment, and runs the README-style normalization/validation smoke path from the installed package.

## Scope boundary

This release deliberately does not include broker or exchange login, proprietary SDK material, production database integration, private market data, strategies, factors, signals, sizing, execution, or arbitrage logic. Checkpoint/recovery orchestration is also deferred until a concrete public use case justifies a stable abstraction.

## Distribution

The repository can build standard Python wheel and source artifacts. PyPI publication is not part of this initial GitHub release and may be added later using a dedicated publishing workflow.
