# v0.3.0 — Offline Audit CLI & JSON Reports

Use the existing session-aware market-data audit from local CSV files and CI
without writing integration code or installing a proprietary provider SDK.

## Highlights

- `mdr-audit` and `python -m marketdata_reliability` accept explicit bars/windows CSV.
- Versioned JSON report projections through `report_to_dict` and `report_to_json`.
- Distinct exit codes: accepted audit (0), completed audit with rejected findings (1), and incomplete input/configuration/output handling (2).
- Explicit-offset timestamps, exact decimal parsing, bounded input, safe parser messages, and no-overwrite output files.
- Structured instrument identities and decimal-string coverage; no raw OHLCV payload is appended to the report.
- Fully synthetic clean and broken CSV fixtures with expected results.
- Linux Python 3.11/3.12/3.13 and Windows Python 3.13 CI, plus clean installed-wheel CLI and legacy-API smoke verification.
- Source distributions include documentation, examples, and tests. CI retains wheel/source candidates, checksums, and a synthetic audit report.
- GitHub Actions pinned to verified commit IDs, read-only repository permissions, non-persisted checkout credentials, and updated SPDX license metadata.

## Compatibility and limits

All 28 previous root exports remain; two report serializers are added. Existing
audit counting, severity policy, validation, observation IDs, lineage hashes,
correction checks, and historical membership implementations are unchanged.
Coverage measures presence, not correctness. CLI warning policies do not repair
data. CSV timestamps are strict and window intervals use whole seconds; the
Python API remains available for custom adapters and finer intervals.

The CLI is bounded batch processing, not a streaming service or hostile-filesystem
sandbox. Output writes are exclusive but not durable atomic transactions. Report
messages and instrument identifiers still need review before public disclosure.
No runtime third-party dependency, provider integration, private data, strategy,
trading execution, PyPI publication, or independent security-audit claim is added.

See `docs/QUICKSTART.md`, `docs/JSON_REPORT.md`, and `docs/MAINTENANCE.md`.
